# Punto 6 — Análisis del archivo .pcap

**Responsable:** David

## Qué va aquí

- El archivo `.pcap` original (el mismo que está en la carpeta del taller).
- `filtros-wireshark.md` — los filtros de Wireshark que usaste, en orden,
  con una línea de qué mostraba cada uno.

El paso a paso completo con capturas, las credenciales encontradas, la flag y
el mapeo a OWASP Top 10 van en el Google Doc, sección Punto 6. Aquí solo el
archivo fuente y el registro técnico de filtros para que cualquiera pueda
reproducir el análisis.

> Nota: si el `.pcap` pesa mucho, verifica el límite de tamaño de archivo de
> GitHub (100 MB por archivo en el plan gratuito) antes de subirlo.
